# วางแผนภาษีจากยอดสะสมในสลิป

เว็บแอปหน้าเดียวสำหรับคำนวณและวางแผน **ภาษีเงินได้บุคคลธรรมดา** ของมนุษย์เงินเดือน
กรอกยอดสะสม 4 ช่องจากสลิปเดือนล่าสุด แล้วเห็นภาษีทั้งปีทันที

## แนวคิด

แทนที่จะให้กรอกเงินเดือนย้อนหลังทีละเดือน แอปใช้ **ยอดสะสม (YTD)** ที่อยู่ในสลิปอยู่แล้ว
เพราะยอดสะสมคือเงินที่ได้รับจริง — การปรับเงินเดือนกลางปี โอที เงินตกเบิก และการเปลี่ยน
อัตรากองทุนสำรองเลี้ยงชีพ รวมอยู่ในนั้นเรียบร้อยโดยไม่ต้องถามซ้ำ

```
ภาษีทั้งปี = ยอดสะสมถึงเดือนสลิป + (เงินเดือนปัจจุบัน x เดือนที่เหลือ) + โบนัส
```

## สิ่งที่คำนวณให้

- เงินได้พึงประเมินทั้งปี หักค่าใช้จ่าย 50% (สูงสุด 100,000)
- ค่าลดหย่อนตามประมวลรัษฎากร พร้อมตัดเพดานอัตโนมัติ
  ส่วนตัว / คู่สมรส / บุตร / บิดามารดา / คนพิการ / ฝากครรภ์
  ประกันสังคม / กองทุนสำรองเลี้ยงชีพ / ประกันชีวิต / ประกันสุขภาพ
  RMF / SSF / ประกันบำนาญ / กอช. / Thai ESG (รวมกลุ่มเกษียณไม่เกิน 500,000)
  ดอกเบี้ยบ้าน / Easy E-Receipt / เงินบริจาค (การศึกษาหัก 2 เท่า)
- ภาษีแบบขั้นบันได พร้อมแผนภูมิบอกว่าอยู่ขั้นไหน
- เทียบกับภาษีหัก ณ ที่จ่ายที่ถูกหักไปแล้ว บอกว่าต้องจ่ายเพิ่มหรือขอคืนได้เท่าไร
- ตัวช่วยวางแผน เลื่อนดูว่าลดหย่อนเพิ่มอีกเท่าไร ประหยัดภาษีได้เท่าไร

## จุดที่ระวังให้แล้ว

- **โบนัสนับซ้ำ** ถ้าโบนัสจ่ายไปก่อนเดือนสลิป แปลว่ารวมอยู่ในยอดสะสมแล้ว ระบบจะไม่บวกเพิ่ม
- **เลือกเดือนสลิปผิด** มีบรรทัดตรวจว่ารายได้สะสมเฉลี่ยต่อเดือนสมเหตุสมผลไหม
- **กองทุนสำรองเลี้ยงชีพ** หักจากฐานเงินเดือนเท่านั้น ไม่รวมโบนัส และเพดาน 15%
- **เปลี่ยนอัตราสะสมกลางปี** ใส่อัตราใหม่กับเดือนที่เปลี่ยนได้ ระบบคิดแยกรายเดือน

## ความเป็นส่วนตัว

ทุกอย่างทำงานในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งข้อมูลออก
ตัวเลขที่กรอกเก็บใน `localStorage` ของเครื่องที่เปิดเท่านั้น
เปิดคนละเครื่องจะเป็นฟอร์มเปล่า ข้อมูลไม่ซิงก์ข้ามเครื่อง

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต
(ถ้าออฟไลน์จะใช้ฟอนต์ระบบแทน ส่วนที่เหลือทำงานครบ)

## ข้อจำกัด

ตัวเลขเป็นการประมาณการเพื่อวางแผนเท่านั้น ยอดจริงยึดตามการยื่นแบบกับกรมสรรพากร
อัตราและเพดานค่าลดหย่อนอาจเปลี่ยนตามประกาศของแต่ละปีภาษี
